# Design

## Context

Генерация — чистый `RecurringLessonPlanner` в domain, вызываемый в транзакции `LessonDao.generateForChild`; DAO передаёт ему и занятия ребёнка, и все занятия расписания. Ручное `addLesson` пересечения уже разрешает; отображение пересечений задано в browse-schedule.

## Goals / Non-Goals

**Goals:**
- Убрать проверку пересечений из генерации, сохранив дедупликацию по «ребёнок / точное начало».
- Убрать счётчик «конфликты» из модели и текста результата.

**Non-Goals:**
- Не менять ручное создание/редактирование/удаление занятий, их валидацию и отображение.
- Не менять схему БД, миграции, DI и навигацию.

## Decisions

- `RecurringLessonPlanner.plan(schedule, childId, now, childLessonSpans)` — параметр `allLessonSpans` и список занятых интервалов удаляются: это прямое следствие нового правила, а не альтернатива (альтернатива «игнорировать параметр» оставила бы мёртвую нагрузку и лишний DAO-запрос).
- Дедупликация внутри запуска сохраняется через множество начал: две строки шаблона с одинаковым началом не создают два занятия, вторая считается «уже существует» — совпадает с сохранённым правилом для зановых записей.
- `finish` продолжает вычисляться, чтобы непредставимая длительность давала `InvalidSchedule` как раньше.
- `GenerationCounts(created, existing)` — поле `conflicts` удаляется; конструктор с дефолтами сохраняет пустой результат `GenerationCounts()`.
- `LessonDao` перестаёт читать все интервалы (`findLessonSpans` удаляется), транзакция короче; `LessonSpanRow` остаётся для занятий ребёнка.
- Текст результата: «Создано: N; уже существуют: M».

## Risks / Trade-offs

- [Дубли при одинаковом начале из двух строк шаблона с разной длительностью не создаются] — правило дедупликации сохранено намеренно; поведению «первая строка побеждает» соответствует сценарий «Повтор и существующее групповое занятие — 11» и тест одинакового начала.
- [Пользователь, ожидавший защиту от конфликтов, получит пересечения] — задуманное изменение поведения, зафиксировано в дельте; ручная приёмка подтверждает счётчики.
- [Эмулятор недоступен] — проверка unit-тестами, Robolectric-интеграцией и компиляцией androidTest; device-сценарий остаётся в ручной приёмке.
