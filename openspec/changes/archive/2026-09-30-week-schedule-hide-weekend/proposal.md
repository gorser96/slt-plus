# Proposal

## Why

Недельная сетка расписания служит для планирования рабочей недели, а суббота и воскресенье для многих логопедов — выходные, которые не планируются: два пустых столбца зря сужают рабочие дни. Нужна настройка, прячущая выходные из недельной сетки.

## What Changes

- Новый переключатель «Скрывать выходные» на экране настроек: при включении недельная сетка показывает только пять дней — с понедельника по пятницу.
- Настройка хранится между запусками приложения (SharedPreferences, без новых зависимостей); значение по умолчанию — выходные показаны (текущее поведение сохранено).
- При включённой настройке занятия субботы и воскресенья не показываются в недельной сетке; занятие, переходящее через полночь в скрытый день, видно только в части на видимый день.
- Месячный режим, дневной список и детали занятия не меняются.

## Capabilities

### New Capabilities

- `app-settings`: экран настроек — переключатель «Скрывать выходные», значение по умолчанию и сохранение между запусками.

### Modified Capabilities

- `browse-schedule`: требование «Недельная сетка» — семь дней по умолчанию и пять (пн–пт) при включённой настройке; сценарий 5 «Начального периода» — диапазон показанной недели зависит от настройки.

## Impact

- `com.logoped_plus`: `AppContainer.kt` (общий экземпляр настроек), `App.kt` (подключение ViewModel настроек).
- `com.logoped_plus.data.preferences` (новый пакет): `SettingsStore` на SharedPreferences с реактивным `StateFlow`.
- `com.logoped_plus.ui.screen`: `SettingsScreen.kt` (заглушка → реальный экран) + `SettingsViewModel`.
- `com.logoped_plus.ui.screen.schedule`: `ScheduleUiState.kt` (флаг), `ScheduleViewModel.kt`/`ScheduleViewModelFactory.kt` (подписка на настройку), `WeekScheduleView.kt` (5/7 столбцов), `ScheduleScreen.kt` (передача флага).
- Карта пакетов: новый `PACKAGE.md` для `data.preferences`, правки в картах `com.logoped_plus`, `ui.screen`, `ui.screen.schedule` и `PACKAGES.md`.
- Без изменений: модель данных, Room-схема, месячный режим, `WeekTimeline.kt` (клиппинг span'ов по дню уже покрывает полночь).
- Замечание: в исходниках есть только `WeekTimelineTest` (JVM); тесты, перечисленные в картах пакетов (androidTest, `ScheduleViewModelTest`, `Example*Test`), на диске отсутствуют — проверять по фактическому состоянию, карты привести в порядок в рамках изменения.
