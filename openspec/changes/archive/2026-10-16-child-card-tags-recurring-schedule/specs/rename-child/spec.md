# Переименование через карточку

## MODIFIED Requirements

### Requirement: Открытие переименования

Система SHALL по нажатию на ребёнка открывать карточку в режиме просмотра; действие «Редактировать» SHALL открывать редактор с текущим именем.

#### Scenario: Текущее имя в форме
- **GIVEN** в списке есть ребёнок «Анна»
- **WHEN** нажать запись, затем «Редактировать»
- **THEN** открывается редактор карточки с именем «Анна».

## Обновление связанных разделов при синхронизации

В неизменных требованиях имени слово «диалог» трактуется как редактор карточки; при синхронизации заменить UI-термин без изменения правил. Удалить граничное условие «Диалог не предоставляет редактирование других данных ребёнка»; поля карточки заданы в child-card.
