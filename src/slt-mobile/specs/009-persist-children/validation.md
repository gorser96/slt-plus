# Проверка сохранения детей в БД

Обновлено: 2026-09-11. Реализация выполнена; окончательная приёмка продолжается.

## Подтверждённые проверки

- Room 2.8.4, KSP 2.3.10, AGP 9.4.0: генерация DAO, экспорт схемы v1 и сборка debug APK/test APK успешны.
- `:app:testDebugUnitTest`: 13 тестов, 0 ошибок; из них один ExampleUnitTest не засчитывается как покрытие функции.
- `:app:connectedDebugAndroidTest` на PJE110 / Android 14: 8 тестов, 0 ошибок; один ExampleInstrumentedTest — шаблонный.
- Файловая БД: 20 детей, два тёзки, нормализация имени, идемпотентный повтор, конфликт UUID, переименование, NotFound и восстановление после закрытия/нового открытия.
- Управляемые ошибки: повтор чтения, сохранность последнего снимка, отсутствие ложного успеха, отмена coroutine.
- UI: повтор загрузки внутри диалога, сохранность имени, блокировка во время записи, пересоздание Activity и Back; ошибка загрузки не сбрасывает комментарий занятия.
- Локальные тесты сначала выявили отсутствие записи в каркасе и отсутствие защиты расписания. После реализации соответствующие тесты прошли.

## Исправленные препятствия

- KSP 2.2.10-2.0.2 несовместим с built-in Kotlin AGP: заменён на 2.3.10. coroutines-test согласован с core 1.9.0.
- Первая UI-проверка состояния кнопки обращалась к немерженному текстовому узлу. Исправлено обращение к самой кнопке; повторный прогон успешен.
- Gradle удаляет инструментальную установку после тестов. Для отдельного стенда debug APK установлен повторно.
- Самостоятельный сервис проверки транзакций находится в debug source set, защищён DUMP permission и отсутствует в release. Использует только отдельные probe-файлы.

- Идентификаторы успешных запусков: добавление BEFORE_COMMIT — `d27653d9478e465dae833cb1adb51d7e`; переименование BEFORE_COMMIT — `f876831e2889471aa3a27b383e416340`; добавление AFTER_COMMIT — `a457a000d7f54df0851fd5cd7c671354`; переименование AFTER_COMMIT — `5b45ffba3d594e74b4cbbdc09687aff2`.
- Перезагрузка PJE110 отложена по прямому решению пользователя 2026-09-11. Телефон не перезагружался.
- Полная ручная приёмка SC-001–005, включая перезагрузку телефона и работу без сети, ещё не подтверждена. Закрытие БД и пересоздание Activity не выдаются за перезагрузку устройства.

Существующие пользовательские данные не очищались. Начальные демонстрационные данные удалены из исходников; занятия по-прежнему хранятся только в памяти процесса.
