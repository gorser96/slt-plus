# Спецификация функции: Видеовложения занятия

**Каталог функции**: `007-lesson-videos`

**Создано**: 2026-09-09

**Статус**: Ретроспективная спецификация; поведение установлено чтением кода, приёмка на устройстве не выполнена.

**Основание**: Запрос пользователя описать уже реализованные функции как примеры SDD.

**Цель**: Логопед связывает существующие видео с занятием, открывает их и убирает ненужные связи.

## Пользовательские сценарии и проверка

### История 1 — Прикрепить видео (приоритет P1)

**Ценность и приоритет**: Связывает материал с занятием.

**Независимая проверка**: Выбрать доступное видео, сохранить занятие и повторно открыть.

**Сценарии приёмки**:

1. **Дано** открыты детали или редактирование; **когда** выбрать несколько доступных видео; **тогда** они появляются в черновике списка; после сохранения и повторного открытия остаются у занятия.
2. **Дано** видео уже выбрано; **когда** выбрать ту же ссылку повторно; **тогда** дубликат не добавляется.
3. **Дано** открыт выбор; **когда** отменить его; **тогда** список не меняется.
4. **Дано** к части выбранных файлов нельзя получить доступ; **когда** завершить выбор; **тогда** доступные добавляются, показано количество неудачных прикреплений.

### История 2 — Открыть и открепить (приоритет P2)

**Ценность и приоритет**: Позволяет использовать материал и поддерживать его актуальность.

**Независимая проверка**: Открыть видео, затем отменить и подтвердить открепление.

**Сценарии приёмки**:

1. **Дано** есть доступное видео и приложение просмотра; **когда** нажать ссылку; **тогда** открывается внешнее приложение просмотра.
2. **Дано** нет приложения просмотра или доступ запрещён; **когда** нажать видео; **тогда** показано сообщение о соответствующей ошибке.
3. **Дано** нажато «Открепить»; **когда** отменить подтверждение; **тогда** видео остаётся в списке.
4. **Дано** нажато «Открепить»; **когда** подтвердить и сохранить занятие; **тогда** связь исчезает, сам файл остаётся на устройстве.
5. **Дано** список изменён в деталях без сохранения; **когда** закрыть и вновь открыть занятие; **тогда** отображается прежний сохранённый список.

### Граничные случаи

- Одинаковый физический файл через разные ссылки не распознаётся как дубликат.
- Новые видео можно открыть до сохранения связи.
- Изменение только порядка ссылок не считается изменением набора для кнопки сохранения в деталях.

## Требования

### Функциональные требования

- **FR-001**: Система должна: позволять выбрать несколько существующих видео из деталей и редактирования; добавлять доступные ссылки без повторов одной ссылки.
- **FR-002**: Система должна: применять прикрепление и открепление к занятию только при сохранении; отмена выбора файлов не меняет список.
- **FR-003**: Система должна: показывать имя видео, а при недоступности имени — «Видео»; открывать ссылку во внешнем приложении.
- **FR-004**: Система должна: запрашивать подтверждение открепления; отмена оставляет список прежним, подтверждение убирает связь из черновика, не удаляя файл.
- **FR-005**: Система должна: сообщать об отсутствии средства выбора или просмотра, отказе доступа и некорректной ссылке при открытии; при частичном отказе прикрепления добавлять доступные файлы и сообщать число неудачных.
- **FR-006**: Система должна: отбрасывать несохранённый список при закрытии деталей; передавать его в редактирование и сохранять прежний черновик деталей при отмене формы.

### Основные сущности

- Видеовложение: ссылка на существующий файл, связанная с одним занятием.
- Черновик вложений: набор выбранных ссылок до сохранения.

## Критерии успеха

### Измеримые результаты

- **SC-001**: Повторный выбор одной ссылки оставляет одно вложение; после сохранения повторное открытие показывает выбранный набор (FR-001–002).
- **SC-002**: Отмена открепления сохраняет связь, подтверждение с сохранением удаляет только связь (FR-004, FR-006).
- **SC-003**: Доступное видео передаётся приложению просмотра; перечисленные ошибки сопровождаются сообщением (FR-003, FR-005).

Это критерии повторяемой приёмки, а не отчёт о пройденных тестах или измеренной производительности.

## Допущения, зависимости и границы

- **Входит**: Множественный выбор существующих видео, открытие во внешнем приложении, открепление с подтверждением, сохранение списка и сообщения об ошибках.
- **Не входит**: Съёмка, встроенный проигрыватель, загрузка на сервер, удаление файлов, видео при создании занятия.
- **Зависимости**: Требуется занятие. Для успешного выбора и открытия нужны доступные файлы и приложения устройства. Сохранение в деталях одновременно применяет комментарий.
- Все сценарии изменения данных ограничены текущим экземпляром приложения. Постоянное хранение и восстановление после завершения процесса не гарантируются.
- Приоритеты историй показывают ценность для изучения и приёмки, а не исторический порядок разработки.
